## Суть продукта

Изолированный приватный браузер — приложение со встроенным браузерным движком и собственным зашифрованным транспортом поверх TLS.

**Не создаёт системный VPN-интерфейс. Не меняет маршрутизацию устройства. Не перехватывает трафик других приложений.**

Для ОС — это просто приложение, которое общается со своим сервером. Внутри — полноценный браузер с изолированным зашифрованным каналом.

---

## Архитектура (утверждена)

```
[UI приложения]
       │
       ▼
[Изолированный Web Runtime]
  Android: GeckoView
  iOS:     WKWebView + локальный HTTP-сервер
  Windows: WebView2 / Tauri WebView
       │
       ▼
[Локальный прокси — 127.0.0.1:порт]
  SOCKS5 / HTTP прокси внутри процесса
  Принимает трафик от Web Runtime
       │
       ▼
[Транспортный модуль — кастомный протокол поверх TLS]
  Полный контроль над протоколом
  Шифрование, обфускация, обход DPI
  Для ОС выглядит как обычный TLS-поток
       │
       ▼
[Сервер-шлюз]
  Декапсуляция, расшифровка
  Реальный запрос от имени сервера
       │
       ▼
[Целевой веб-сервис]
  web.telegram.org, web.whatsapp.com, etc.
```

---

## Жизненный цикл запроса

1. Пользователь нажимает иконку сервиса (например, Telegram)
2. Приложение открывает `web.telegram.org` в GeckoView/WKWebView
3. Весь трафик Web Runtime направлен на `127.0.0.1:порт` (локальный прокси)
4. Прокси упаковывает запрос в кастомный TLS-протокол
5. Транспортный модуль отправляет на сервер-шлюз
6. Сервер делает реальный запрос к Telegram, возвращает ответ по той же цепочке
7. Пользователь видит работающий Telegram Web

**Для провайдера/DPI:** обычный TLS-поток к известному серверу.  
**Для ОС:** приложение общается со своим сервером.  
**Значок VPN:** не появляется (нет VpnService / NetworkExtension).

## Технический стек

### Мобильный / Desktop UI
- **Flutter (Dart)** — единая кодовая база для Android, iOS, Windows, Android TV
- Нативные платформенные плагины для браузерного движка и транспорта

### Браузерный движок
- **Android:** `GeckoView` — независим от системного WebView, полный контроль прокси через `GeckoRuntimeSettings.setProxy()`
- **iOS:** `WKWebView` + `WKURLSchemeHandler` + локальный HTTP-сервер для перехвата
- **Windows:** `WebView2` или Tauri встроенный WebView

### Транспортный протокол
- **Кастомный протокол поверх TLS**
- Полный контроль над структурой пакетов
- Обфускация трафика — выглядит как легальный HTTPS
- Реализация: Rust (производительность, кроссплатформенность) или Go

### Серверная часть
- Сервер-шлюз: Go или Rust
- Декапсуляция входящего протокола
- Обычный HTTP(S)-запрос к целевому сервису

## Почему значок VPN не появляется

| Что создаёт VPN-значок | Что делает этот продукт |
|------------------------|------------------------|
| `VpnService` (Android) | ❌ Не используется |
| `NetworkExtension` (iOS) | ❌ Не используется |
| Системный tun/tap интерфейс | ❌ Не создаётся |
| Изменение routing table ОС | ❌ Не меняется |
| **Итого:** | Для ОС — обычное приложение |

## Преимущества модели

- **Нулевой порог входа:** скачал → открыл → нажал иконку → работает
- **Банки не ломаются:** системный трафик не затронут, антифрод-системы не срабатывают
- **Модерация сторов:** нет VPN-кода → нет претензий от Apple/Google
- **Устойчивость к DPI:** кастомный TLS-протокол не раскрывает содержимое
- **Изоляция:** падение/блокировка не влияет на другие приложения

## Коммерческие модели

| Модель | Целевая аудитория |
|--------|-----------------|
| **Workspace Secure Browser** | Компании без MDM/VPN — защищённый доступ к веб-сервисам |
| **Personal Privacy Container** | Пользователи с заблокированными сервисами |
| **Compliance Browser** | Корпоративный рынок — совместим с банковскими/корп. приложениями |
| **Anti-Tracking Browser** | Фокус на приватности: cookie, fingerprint, история |
